# 紫禁城 · 体素沙盘

以体素方块逐殿复原的明清紫禁城(Forbidden City Voxel Sandbox),基于 Three.js,零外部依赖、完全离线可运行。

## 启动

双击 **`启动沙盘.bat`**(自动打开浏览器),或手动:

```bash
node server.js          # 然后访问 http://127.0.0.1:8137/
```

> 需用 HTTP 方式访问(ES Module 不能从 file:// 直接加载),本目录自带 `server.js` 静态服务器。

## 玩法

| 模式 | 操作 |
| --- | --- |
| 🗺 上帝视角 | 左键拖拽旋转 · 滚轮缩放(可近观到几十米、远观全城)· 右键/中键平移 · WASD 平移 · 悬停建筑看介绍 · 点击建筑或景点名录飞越 |
| 🚶 第一人称 | `2` 进入,WASD 行走 · 空格跳跃 · Shift 奔跑 · `F` 切换飞行(空格上升 / Ctrl 下降) · 鼠标环视,可穿行午门门洞、登临三台丹陛、漫步御花园 |
| 其他 | `N` 昼夜 · `L` 标注 · `M` 景点名录 · `H` 帮助 · `1/2` 切换视角 · Esc 释放鼠标 |

## 复原内容

- **中轴线**:天安门(华表·外金水河五桥)→ 端门 → 午门(凹字形城台·雁翅楼·五门洞)→ 内金水河五桥 → 太和门 → 三台之上的太和殿 / 中和殿 / 保和殿(体仁阁·弘义阁)→ 乾清门 → 乾清宫 / 交泰殿 / 坤宁宫 → 坤宁门 → 御花园(钦安殿·万春亭·千秋亭·浮碧亭·澄瑞亭·堆秀山)→ 神武门
- **前朝两翼**:文华殿、文渊阁(黑瓦)、武英殿、断虹桥
- **内廷**:东六宫、西六宫(各六座宫院)、奉先殿、斋宫、毓庆宫、箭亭、乾东五所、南三所
- **外东路**:宁寿宫区(九龙壁、皇极殿、宁寿宫、养性殿、畅音阁三层大戏楼、乾隆花园)
- **外西路**:慈宁宫及花园、寿康宫、寿安宫、雨花阁(四层佛楼)、重华宫
- **城防**:宫墙与垛口、护城河(筒子河)、四座角楼、东/西华门
- **城外**:太庙(三重享殿)、社稷坛(五色土)
- 细节:琉璃瓦屋顶分层、正脊鸱吻、斗拱、门钉、汉白玉须弥座与栏杆、丹陛石雕、铜缸、铜鹤龟、石狮、华表、九龙壁、古柏与太湖石

## 技术

- `js/buildCity.js` — 程序化城市生成器(布局数据 + 体素放置 + 高度图碰撞)
- `js/main.js` — 渲染(分块 InstancedMesh 实例化、天空穹顶、水面着色器、昼夜)、双模式相机、景点标注与飞越
- 体素以 1 米为基本单位,总方块数约数十万级,按 128m 分块实例化渲染并做视锥剔除,集成显卡亦可流畅运行
- `test-build.mjs` — Node 无头冒烟测试(构建全城并校验数据)
- 体素以 1 米为基本单位,全城约 2.5 万实例构件(殿宇墙体、屋顶分层、瓦垄、斗拱、栏杆、门钉等细部),按 128m 分块实例化渲染并做视锥剔除,集成显卡亦可流畅运行
